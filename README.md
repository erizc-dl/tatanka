# TATANKA — a Lakota history

A choose-your-own-adventure history game set among the Hunkpapa and Oglala Lakota from 1855 to 1890. Built as an 8th grade U.S. History final project. Play as a Lakota man living through one of the most consequential eras in American history — the buffalo slaughter, the Black Hills crisis, the Battle of the Little Bighorn, the Ghost Dance, and Wounded Knee. Every named leader in the game (Sitting Bull, Crazy Horse, Red Cloud, Spotted Tail, Big Foot) was a real person. Every major event is documented. The game contains approximately 75 scenes across three acts, nine possible endings, two playable minigames (a Buffalo Hunt and a Ration Line), and takes 30–45 minutes per playthrough. Seven primary sources and ten secondary sources are cited in the in-game Historical Notes menu.

## How to Play

**Option 1 — Online:** Visit [tatankaonline.com](https://tatankaonline.com)

**Option 2 — Local:** Unzip the folder and double-click `index.html`. No install, no server required. Fonts load from Google on first open; the game still works offline with system fallback fonts. If Chrome blocks local file audio, open in Firefox or run `python3 -m http.server 8000` in the project folder and visit `http://localhost:8000`.

**Controls:**

| Input | Action |
|---|---|
| Number keys `1`–`4` | Select a choice |
| `SPACE` or click | Skip typewriter reveal |
| `ESC` | Open/close pause menu |
| `↑` / `↓` | Navigate title menu |
| `Enter` | Confirm title menu selection |

The game auto-saves on every scene transition. Click **Continue** on the title screen to resume where you left off.
