## Section 5 — Deployment Checklist

Work through these steps after all assets are in place.

- [ ] **Verify the game works locally** — open `index.html` directly in Chrome. Check all 9 endings and confirm no console errors.

- [ ] **Create a GitHub account** (if you don't have one) at github.com

- [ ] **Initialize git and push:**
  ```bash
  cd /path/to/Tatanka
  git init
  git add .
  git commit -m "Tatanka v1.0 — 8th grade final project"
  ```
  Then create a new public repository on GitHub named `tatanka`, and follow the push instructions GitHub shows you.

- [ ] **Enable GitHub Pages:**
  In the repo → Settings → Pages → Source: Deploy from a branch → Branch: `main` → Folder: `/ (root)` → Save.
  GitHub will show a URL like `https://yourusername.github.io/tatanka`. Verify it works.

- [ ] **Add custom domain in GitHub Pages settings:**
  In the same Pages settings page, enter `tatankaonline.com` in the Custom Domain field → Save. GitHub will verify the CNAME file (already created by Claude Code).

- [ ] **Configure DNS at the domain registrar:**
  Log into wherever `tatankaonline.com` was purchased. Add a CNAME record:
  - Host/Name: `@` (or blank, or `tatankaonline.com` depending on the registrar)
  - Points to: `yourusername.github.io` (NOT `/tatanka` — just the root github.io domain)
  - TTL: 3600 (or lowest available)

- [ ] **Wait for DNS propagation** (10–30 minutes, sometimes up to 2 hours)

- [ ] **Enable HTTPS:** Back in GitHub Pages settings, check "Enforce HTTPS" once it becomes available (it activates after DNS propagates). This enables the padlock icon.

- [ ] **Final verification:**
  - Load `https://tatankaonline.com` on a phone, on the school laptop, and in a second browser
  - Complete one full playthrough on the live site
  - Check that audio plays (you may need to click once to unlock audio on mobile)

- [ ] **Zip for backup submission:**
  ```bash
  cd ..
  zip -r tatanka.zip Tatanka/ -x "*.DS_Store" -x "Tatanka/tools/*" -x "Tatanka/*.pdf"
  ```
  Submit the live URL to the teacher, with the zip as a backup.
